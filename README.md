# 榆林图书馆「AI融合的智慧服务创新」——「榆小图」文化服务智能体

> 一份可参赛、可落地、可演示的完整竞赛作品全案
> 面向人群：青少年读者 · 老年读者 · 普通市民
> 文化内核：榆林馆藏 · 路遥文学 · 陕北非遗 · 红色文化 · 地方文献

---

## 一、项目一句话定位

以**榆林本地文化知识库**为底座，以**「榆小图」AI 智能体**为入口，以**分层 Skills 技能库**为能力引擎，以 **MCP 数据服务**为数据中枢，打造一套轻量化、全人群、可落地的图书馆 AI 智慧服务系统——让每一本书都遇见懂它的人，让陕北文化被每一个年龄段的人读懂。

## 三、快速开始

**演示 Demo：**
直接双击打开 `demo/index.html`，无需任何环境、依赖或网络配置。包含：系统介绍、功能展示、智能体交互演示（模拟对话）、技能库展示、架构图可视化。

**查看文档：**
按 `docs/` 目录内编号顺序阅读，即构成从"理论架构 → 数据逻辑 → 功能设计 → 可视化 Demo"的完整闭环。

## 四、核心亮点速览

1. **专属而非通用**——知识库限定榆林馆藏 + 路遥 + 陕北非遗 + 红色文化 + 地方文献，拒绝套模板。
2. **Agent + Skills + MCP 三层解耦**——智能体负责"对话与调度"，技能库负责"能力"，MCP 负责"数据"，可复用、可扩展、可落地。
3. **全人群覆盖**——少儿趣味科普、青少年深度导读、中老年极简大字服务，社会价值高。
4. **低成本可落地**——无真实后端即可演示，模拟数据架构完整，可平滑接入真实馆藏系统。
5. **文化传播创新**——把"图书馆"从"借书的地方"升级为"文化陪伴者与陕北文化的数字化传播者"。
