# 08 · 适配三类人群的差异化服务方案

## 一、差异化服务总览

| 维度 | 少儿/低龄读者 | 青少年读者 | 中老年读者 |
|---|---|---|---|
| **核心诉求** | 有趣、好玩、听得懂 | 有深度、有收获、有素材 | 简单、字大、听得清 |
| **服务重点** | 趣味科普、故事、绘本 | 导读、名著拆解、作文素材 | 极简咨询、大字解读、适老活动 |
| **语言风格** | 童趣、故事化、短句 | 平等、共情、有深度 | 通俗、大字、可语音 |
| **交互方式** | 语音 + 卡通 + 点击 | 对话 + 深度内容 | 大字按钮 + 语音播报 + 方言 |
| **对应技能组** | 少儿技能组 | 青少年技能组 | 中老年技能组 |

---

## 二、少儿/低龄读者服务方案

### 2.1 服务目标

在趣味中播下阅读与文化的种子，让孩子**愿意来、听得懂、记得住**。

### 2.2 差异化设计

1. **趣味化科普**：把陕北非遗讲成"会说话的故事"（拟人化、有画面、有悬念）。
2. **故事化改编**：把路遥少年故事、陕北民间传说改编成 3 分钟童趣版。
3. **绘本文案生成**：生成"红枣、窑洞、剪纸、腰鼓"等陕北主题绘本分镜。
4. **简单诗词解读**：把古诗、信天游用"大白话 + 画面感"讲给孩子。
5. **互动激励**：阅读勋章、闯关式打卡，激发阅读兴趣。

### 2.3 典型场景

> 孩子问：「陕北的窑洞为什么是圆的？」
> 榆小图：「因为黄土又厚又结实，挖个洞洞就能住，冬暖夏凉！圆拱形的顶子特别结实，就像鸡蛋壳一样，压不垮。你想不想听一个住在窑洞里的小羊倌的故事呀？」

## 三、青少年读者服务方案

### 3.1 服务目标

提供**有深度的阅读支持**，让青少年在阅读中汲取精神力量、积累写作素材。

### 3.2 差异化设计

1. **阅读导读**：读前输出"导读 + 时代背景 + 阅读地图"，降低名著门槛。
2. **名著拆解**：拆成"人物谱 + 情节线 + 主题"三张图，辅助理解。
3. **路遥深度解析**：结合榆林本土，深度解读《人生》《平凡的世界》的现实意义。
4. **作文素材生成**：从路遥金句、陕北人物提炼可引用的写作素材。
5. **阅读计划定制**：生成"路遥专题 30 天阅读计划"等个性化规划。

### 3.3 典型场景

> 学生问：「《平凡的世界》里孙少平为什么要坚持读书？」
> 榆小图：「这是全书的精神内核。对孙少平而言，**读书是他在苦难中保持尊严与梦想的唯一方式**。路遥本人就是靠读书从清涧走出来的——他相信，书能改变一个人的眼界，眼界决定命运。这个回答可以直接用进你的读后感里，要我再给你补两个论证角度吗？」

---

## 四、中老年读者服务方案

### 4.1 服务目标

**跨越数字鸿沟**，让老人也能轻松享受智慧文化服务，在熟悉的文化中找到归属。

### 4.2 差异化设计

1. **极简咨询**：一句话问答，用最少的字、最清晰的动作说明办证/借还/找书。
2. **大字版解读**：关键内容放大字号、加粗、分步，降低阅读负担。
3. **通俗文化讲解**：用老辈记忆与大白话讲非遗、红色故事，唤起共鸣。
4. **适老活动推荐**：推荐民歌会、戏曲、健步研学等适老活动。
5. **方言 + 语音播报**：支持陕北话问答与语音播报，消除隔阂。

### 4.3 典型场景

> 老人问：「我想听一段陕北说书，有没有？」
> 榆小图（大字 + 语音）：「**有！** 本周六下午三点，图书馆一楼报告厅有"陕北说书"专场，**免费**入场。我帮您记下时间，到时候提前给您语音提醒，好吗？」

---

## 五、差异化服务的底层保障

1. **人群判定引擎**：Agent 通过年龄信息 + 用词特征 + 需求信号，自动判定人群并切换服务模式。
2. **技能分层路由**：不同人群自动路由到对应技能组，输出模板随之切换。
3. **无障碍适配层**：`S-GEN-04` 无障碍技能统一处理大字、语音、方言、简化交互。
4. **数据脱敏画像**：轻量画像支撑"千人千面"，但不采集隐私。

---

## 六、小结

三类人群差异化服务，本质是**公共文化服务均等化**的产品化落地：不因年龄、数字能力、文化水平的差异，把任何一位读者挡在智慧服务之外。
