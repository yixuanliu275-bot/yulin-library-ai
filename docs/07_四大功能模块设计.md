# 07 · 四大核心功能模块详细设计

> 本章详述「AI 智慧便民创新服务」的四大核心功能模块（加分重点）。

---

## 模块一：AI 图书馆陪伴阅读伙伴

### 1.1 功能定位

把"借一本书"升级为"**陪读一本书**"——读者读书遇到困难时，随时有「榆小图」陪在身边答疑、导读、讨论。

### 1.2 核心能力

| 能力 | 说明 |
|---|---|
| 读前导读 | 3 分钟讲清一本书"讲什么、为什么值得读、怎么读" |
| 读中陪读 | 随时解答不懂的段落、生僻词、时代背景 |
| 读后讨论 | 抛出开放性问题，引导深度思考 |
| 打卡激励 | 阅读进度打卡，生成阅读勋章 |

### 1.3 交互示例

> **读者**：「我刚借了《平凡的世界》，但孙少平是谁我有点乱。」
> **榆小图**：「别急，我陪你理一理。孙少平是双水村的一个穷苦少年，他最爱读书，高中毕业后去黄原城当了揽工汉，又下煤矿……他代表的是那种**再苦也要读书、再难也不认命**的陕北精神。你读到哪一章啦？我可以按章节给你划重点哦。」

### 1.4 技术支撑

- 依赖：`MCP-Culture`（作品知识）、`MCP-Reading`（进度打卡）、`S-TEEN-01`（导读）/ `S-KID-02`（故事改编）。

## 模块二：榆林本地文化 AI 科普专栏

### 2.1 功能定位

打造一个**可对话的陕北文化科普专栏**，让非遗、民俗、红色文化、地方文献"开口说话"。

### 2.2 内容形态

| 形态 | 说明 | 示例 |
|---|---|---|
| 每日一非遗 | 每日推送一个非遗故事 | 今天讲"绥德剪纸" |
| 路遥金句台历 | 每日一句路遥金句 + 解读 | "像牛一样劳动，像土地一样奉献" |
| 陕北民俗问答 | 一问一答式科普 | "为什么陕北人爱唱信天游？" |
| 红色记忆 | 红色文化小课堂 | 小河会议的故事 |

### 2.3 交互示例

> **读者**：「陕北说书是啥？跟评书一样吗？」
> **榆小图**：「不完全一样！陕北说书是**弹着三弦、唱出来**的，有说有唱、还有固定的曲调，是咱陕北特有的曲艺，已经列入国家级非遗。说书人最经典的开场——『怀抱三弦定好音，众位乡亲听我明』。想听一段吗？」

### 2.4 技术支撑

- 依赖：`MCP-Culture`（文化知识检索）、分级解读（趣味/通俗/深度）、`S-KID-01`/`S-ELD-03`。

## 模块三：自动生成读书会 / 展览 / 研学活动策划文案

### 3.1 功能定位

做馆员与读者的"**AI 策划助手**"——输入主题，一键生成结构完整、可直接使用的活动策划文案。

### 3.2 三种活动类型

| 活动类型 | 输入 | 自动生成内容 |
|---|---|---|
| 读书会 | 书名/主题 | 活动主题、招募文案、环节设计、讨论题、金句海报文案 |
| 展览 | 主题 | 展陈主题、前言、单元划分、展品清单、导览词 |
| 研学 | 主题/人群 | 研学路线、知识点、任务单、安全须知、成果产出 |

### 3.3 生成示例（读书会·路遥专题）

> **活动主题**：「像土地一样奉献——路遥作品读书会」
>
> **招募文案**：
> 黄土高原上，有一种精神叫"平凡而不平庸"。
> 这个周六，我们邀你共读路遥，聊聊《人生》里的抉择，听听《平凡的世界》里的奋斗。
> 无论你是第一次读路遥，还是他的"老读者"，都欢迎你来。
>
> **环节设计**：
> ① 暖场：陕北民歌《兰花花》开场
> ② 共读：路遥金句接力朗读
> ③ 讨论：如果你是高加林，你会怎么选？
> ④ 分享：每个人心中的"平凡世界"
>
> **讨论题**：
> 1. "平凡"与"平庸"的区别是什么？
> 2. 路遥笔下的奋斗，在今天还有意义吗？

### 3.4 技术支撑

- 依赖：`MCP-Event`（文案生成）、`MCP-Culture`（主题素材）、`S-GEN-03`。

## 模块四：特殊人群无障碍智能服务适配方案

### 4.1 功能定位

让**老年读者、低龄读者、视障读者**都能无障碍使用，践行公共文化服务均等化。

### 4.2 无障碍能力矩阵

| 能力 | 适用人群 | 实现方式 |
|---|---|---|
| 大字版显示 | 老年读者 | 关键内容字号放大、高对比度 |
| 语音播报 | 老年/视障 | 文字转语音，支持陕北方言播报 |
| 简化交互 | 老年/低龄 | "一句话提问"代替多级菜单 |
| 方言支持 | 老年读者 | 支持陕北话口语问答 |
| 手势/语音输入 | 全人群 | 打字、语音、点击三通道 |
| 适老化配色 | 老年读者 | 高对比、大按钮、防误触 |

### 4.3 交互示例（方言播报）

> **老年读者**（陕北话）：「娃娃，我想寻一本路遥的书，咋寻哩？」
> **榆小图**（大字 + 语音）：
> **「叔，您在一楼说一声，或者点这个大字按钮，我帮您找。路遥的《平凡的世界》在二楼文学区，我给您放一段语音导引。」**

### 4.4 技术支撑

- 依赖：`S-GEN-04`（无障碍适配）、`S-ELD-01`（极简咨询）、`S-ELD-02`（大字版）。

---

## 四、模块协同关系

四大模块并非孤立，而是以「榆小图」Agent 为统一入口、以 Skills 为能力、以 MCP 为数据的**协同生态**：

```
陪伴阅读 ──┐
文化科普 ──┼──► 「榆小图」Agent ──► 分层 Skills ──► MCP 数据服务
活动策划 ──┤
无障碍服务─┘
```
