# 05 · 全套分层 Skills 技能库

## 一、技能库设计理念

**"能力组件化、分层可复用、按需自动触发"**

每一个 Skill 都是一个**标准化的能力单元**，包含四个字段：`id`（唯一标识）、`name`（名称）、`target`（适用人群）、`trigger`（触发场景）、`action`（执行动作）。Agent 根据"意图 + 人群"自动匹配并调用。

## 三、少儿/低龄读者技能组（4 项）

| ID | 技能名称 | 触发场景 | 动作说明 |
|---|---|---|---|
| `S-KID-01` | 趣味文化科普 | 孩子问"什么是…/为什么…" | 用拟人化故事讲清非遗/民俗，如"腰鼓为什么这么响？" |
| `S-KID-02` | 故事改编 | 孩子想听故事 | 把陕北传说、路遥少年故事改编为 3 分钟童趣版 |
| `S-KID-03` | 绘本文案 | 家长/馆员要绘本内容 | 生成陕北主题绘本分镜文案（红枣、窑洞、剪纸） |
| `S-KID-04` | 简单诗词解读 | 孩子学古诗/陕北民谣 | 把诗词/信天游用"大白话 + 画面感"讲给孩子 |

**示例（S-KID-01 趣味科普·陕北说书）**：

> 小朋友，你知道吗？很久以前，陕北有个"会讲故事的老爷爷"，他抱着一把三弦琴，走村串户，把英雄的故事、家长里短都唱给大伙听。这就是"陕北说书"。它就像咱们陕北的"有声故事书"，说书人一边弹、一边唱、一边讲，特别热闹！你想听一个说书里的小英雄吗？

## 四、青少年读者技能组（4 项）

| ID | 技能名称 | 触发场景 | 动作说明 |
|---|---|---|---|
| `S-TEEN-01` | 阅读导读 | 读前不知从何入手 | 输出一本书的"导读 + 时代背景 + 阅读地图" |
| `S-TEEN-02` | 名著拆解 | 啃不动名著 | 把名著拆成"人物谱 + 情节线 + 主题"三张图 |
| `S-TEEN-03` | 路遥作品深度解析 | 读路遥/写读后感 | 深度解析《人生》《平凡的世界》的文学价值与现实意义 |
| `S-TEEN-04` | 作文素材生成 | 写作文缺素材 | 从路遥/陕北文化提炼可引用的金句、人物、事例 |

**示例（S-TEEN-03 路遥深度解析·《人生》高加林）**：

> 《人生》的主人公高加林，是改革开放初期陕北农村青年的缩影。他聪明、自尊、不甘平庸，却在"进城"与"回乡"之间一次次挣扎。路遥借他提出了一个永恒之问：**当理想与现实冲突时，人该如何安放自己的灵魂？** 高加林的悲剧不在于他"走错路"，而在于他用"捷径"去换取本应用汗水去赢得的东西。这也是《人生》至今仍能击中我们的原因——**人生要紧处，往往只有几步。**

| ID | 技能名称 | 触发场景 | 动作说明 |
|---|---|---|---|
| `S-GEN-01` | 智能荐书 | 任何"荐书"需求 | 按年龄 + 阅读水平 + 偏好，从馆藏匹配推荐 |

| `S-GEN-04` | 无障碍智能适配 | 无障碍需求 | 触发大字/语音/简化交互/方言播报 |

## 七、技能库标准化与可复用机制

1. **标准化字段**：每个技能统一 `id / name / target / trigger / action` 五字段，可被 Agent 统一解析调用。
2. **可复用**：同一技能可被多个场景复用（如"荐书"技能服务三类人群，仅输出模板不同）。
3. **可扩展**：新增服务只需新增一个 Skill 定义，无需改动系统主体。
4. **可维护**：技能库以结构化文件（`data/skills_catalog.json`）存储，馆员可维护、可版本管理。
5. **自动触发**：Agent 依据"意图识别 + 人群分层"自动路由到对应技能，实现"千人千面"。

---

## 八、技能库价值总结

分层技能库让 AI 能力从"黑盒"变成"**白盒、可组合、可治理**"的组件化资产——这是系统能长期运营、持续迭代、而非一次性演示的关键工程保障。
