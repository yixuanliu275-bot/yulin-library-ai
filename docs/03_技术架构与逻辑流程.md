## 一、总体技术架构（三层四端）

```
┌─────────────────────────────────────────────────────────────────────┐
│                        用户接入端（四端）                              │
│   读者小程序端    │   触屏一体机端    │   微信公众号端    │   馆员后台端   │
└───────────────────────────────┬─────────────────────────────────────┘
                                │  对话 / 交互（自然语言）
┌───────────────────────────────▼─────────────────────────────────────┐
│              第一层：AI 智能体层 —— 「榆小图」Agent                     │
│   ┌─────────────┐  ┌──────────────┐  ┌──────────────┐  ┌─────────┐  │
│   │ 意图识别     │  │ 人群分层判定  │  │ 任务规划调度  │  │ 记忆管理 │  │

│        （用户说的是什么 / 谁在问 / 该调用什么技能 / 记得什么）              │
└───────────────────────────────┬─────────────────────────────────────┘
                                │  技能调度（Skill Dispatch）
┌───────────────────────────────▼─────────────────────────────────────┐
│              第二层：分层 Skills 技能库层                              │
│   ┌──────────────┐  ┌───────────────┐  ┌────────────────────┐        │
│   │ 少儿技能组     │  │ 青少年技能组   │  │ 中老年技能组        │        │
│   │ 趣味科普/故事  │  │ 导读/名著/路遥 │  │ 极简/大字/通俗讲解 │        │
│   └──────────────┘  └───────────────┘  └────────────────────┘        │
│   + 跨人群通用技能：荐书 / 阅读计划 / 活动策划 / 无障碍适配               │
└───────────────────────────────┬─────────────────────────────────────┘
                                │  数据读写（统一 MCP 协议）
┌───────────────────────────────▼─────────────────────────────────────┐
│              第三层：MCP 智慧数据服务层                                │
│   ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐  │
│   │馆藏资源   │ │文化知识库 │ │用户画像   │ │阅读计划   │ │活动事件   │  │
│   │ Catalog  │ │ Culture  │ │ Profile  │ │ Reading  │ │ Event    │  │
│   └──────────┘ └──────────┘ └──────────┘ └──────────┘ └──────────┘  │
└───────────────────────────────┬─────────────────────────────────────┘
                                │
┌───────────────────────────────▼─────────────────────────────────────┐
│              数据底座（模拟数据架构，可替换为真实系统）                   │
│   馆藏数据 │ 用户行为数据(脱敏) │ 文化知识条目 │ 地方文献索引 │ 活动台账  │
└─────────────────────────────────────────────────────────────────────┘
```

**架构设计原则**：

1. **三层解耦**：Agent（大脑）、Skills（能力）、MCP（数据）各司其职，任一层的替换/升级不影响其他层。
2. **数据标准化**：所有数据读写都通过 MCP 标准接口，屏蔽底层异构。
3. **渐进落地**：模拟数据 → 部分真实数据 → 全量接入，平滑演进。

## 二、核心逻辑流程（一条请求的完整旅程）

以"一位 68 岁老人问『给我推荐一本讲路遥的书，字要大点』"为例：

```
用户提问（自然语言）
   │
   ▼
[① 意图识别]  ──► 识别为「图书推荐」意图，抽取实体：路遥 / 老年 / 大字需求
   │
   ▼
[② 人群判定]  ──► 识别为「中老年读者」，加载「中老年技能组」+「无障碍适配」参数
   │
   ▼
[③ 技能调度]  ──► 调用 Skill「老年适读书单推荐」+「大字版解读」
   │
   ▼
[④ MCP 数据调用] ──► 调用 MCP-Catalog 检索馆藏（关键词：路遥、适老、大字号）
   │              ──► 调用 MCP-Profile 读取用户阅读偏好（脱敏）
   │
   ▼
[⑤ 结果生成]  ──► 生成大字版推荐结果 + 通俗导读 + 语音播报开关
   │
   ▼
[⑥ 行为回写]  ──► 将「本次推荐」轻量化回写 MCP-Profile（不含隐私）
```

## 三、四大功能模块逻辑流转

```
                     ┌────────────「榆小图」AI 智能体 ────────────┐
                     │  （统一入口：对话 / 检索 / 推荐 / 咨询）      │
                     └───────────────┬───────────────────────────┘
        ┌────────────────────────────┼────────────────────────────┐
        ▼                            ▼                            ▼
 ┌──────────────┐            ┌──────────────┐            ┌──────────────┐
 │ 模块二        │            │ 模块三        │            │ 模块四        │
 │ 分层Skills    │◄──────────►│ MCP数据服务   │◄──────────►│ 便民创新服务  │
 │ 技能库        │   调度/能力  │ 数据中枢      │   数据支撑   │ 四类场景      │
 └──────────────┘            └──────────────┘            └──────────────┘
```

- **模块一（Agent）**是"大脑"，负责理解、规划、调度；
- **模块二（Skills）**是"能力库"，负责具体服务动作；
- **模块三（MCP）**是"数据血脉"，负责供给数据；
- **模块四（便民服务）**是"应用场景"，负责把能力落到真实服务。

## 四、数据流转逻辑（三级缓存 + 单次回写）

```
实时对话层 ──► 技能执行层 ──► MCP 服务层 ──► 数据底座
   │              │               │
   │              │               ├─ 缓存热数据（高频馆藏、常用文化条目）
   │              │               └─ 回写用户轻量行为（脱敏）
   │              └─ 技能结果按人群模板渲染（大字/趣味/深度）
   └─ 对话记忆会话内临时保留，会话结束即清理（隐私友好）
```

**数据安全设计**：

- 用户画像仅保存**轻量化脱敏字段**（年龄区间、偏好类别、最近阅读主题），不存姓名、手机号、精确位置。
- 对话记忆**会话级临时**，会话结束即清理，不落库。
- 行为数据仅用于**个性化推荐**，不用于任何商业用途。

## 五、技术选型（轻量可落地）

| 层级 | 技术选择 | 说明 |
|---|---|---|
| 前端 | 单页 H5 / 小程序 / 触屏 Web | 零安装，浏览器即用 |
| 智能体 | 大语言模型（可本地部署或 API 调用） | 支持多种模型接入 |
| 技能库 | JSON/YAML 结构化 Skill 定义 | 标准、可维护、可版本管理 |
| 数据服务 | MCP 标准接口 | 统一、可替换、可扩展 |
| 知识检索 | 向量检索（Embedding）+ 关键词匹配 | 本地知识库精准召回 |
| 数据底座 | 模拟 JSON / 轻量数据库 | 演示即用，落地可替换 |
