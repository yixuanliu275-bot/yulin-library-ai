# 榆林图书馆「AI 融合的智慧服务创新」竞赛结题报告（终稿）

**作品名称**：榆林图书馆 AI 融合的智慧服务创新系统
**智能体名称**：「榆小图」
**面向人群**：青少年读者 · 老年读者 · 普通市民
**技术范式**：AI Agent + 分层 Skills 技能库 + MCP 智慧数据服务

---

## 摘要

本项目针对榆林市图书馆在数字化转型中面临的"馆藏资源沉睡、服务形式单一、特殊人群使用门槛高、陕北文化传播乏力"四大痛点，创新性地提出并落地了一套以**本地文化知识库为底座、以「榆小图」AI 智能体为入口、以分层 Skills 技能库为能力引擎、以 MCP 智慧数据服务为数据中枢**的图书馆 AI 智慧服务系统。系统以路遥文学、陕北非遗、红色文化、榆林地方文献为核心知识资产，通过少儿、青少年、中老年三类人群的差异化分层服务，实现"让每一本书都遇见懂它的人，让陕北文化被每一个年龄段的人读懂"的目标。项目无需真实后端即可完整演示，具备轻量化、低成本、可复制、可扩展的落地价值，是一份技术先进、文化独特、社会价值突出的完整竞赛作品。

**关键词**：AI Agent；Skills 技能库；MCP；本地化知识库；公共文化服务；榆林；路遥；陕北非遗

---

## 第一章 项目背景与意义

### 1.1 研究背景

随着人工智能技术的成熟，公共文化服务的数字化、智能化转型已成为国家战略。《"十四五"公共文化服务体系建设规划》明确提出推动公共文化服务智能化，人工智能作为新质生产力正深度渗透公共文化领域。然而，大量市级公共图书馆的数字化建设仍停留在"自助借还、目录检索"的浅层阶段，存在"有系统、无智能、无温度"的普遍问题。

榆林市作为国家级历史文化名城，坐拥路遥文学、陕北非遗、红色文化、地方文献等丰厚文化资源，却在数字化传播与服务创新上长期存在"资源富矿"与"传播洼地"的反差。本项目正是针对这一反差，探索"AI + 本地文化 + 全人群服务"的市级图书馆创新路径。

### 1.2 研究意义

**理论意义**：本项目提出了"Agent—Skills—MCP"三层解耦的公共文化 AI 服务架构范式，为公共文化服务领域的 AI 落地提供了可参考的方法论。

**实践意义**：项目以榆林图书馆为具体场景，产出了从理论架构到数据逻辑、从功能设计到可视化 Demo 的完整闭环，可直接用于试点落地。

**社会意义**：项目通过差异化分层服务与无障碍适配，推动公共文化服务均等化，弥合数字鸿沟，守护与传播陕北地方文化。

## 第二章 痛点分析与问题定义

### 2.1 核心痛点

1. **资源利用率低**：地方文献、古籍、非遗资料因专业性强、门槛高而"沉睡"，读者"不知道有什么、适不适合我"。
2. **服务形式枯燥**：读者体验仍是"查目录—找书—借书—还书"的线性流程，缺乏对话感、陪伴感与个性化。
3. **特殊人群门槛高**：老年读者面对智能检索、App 操作无所适从，字号过小、术语过多进一步拉高门槛。
4. **文化传播单一**：陕北文化传播以静态展览、纸质宣传为主，缺乏年轻化、趣味化、可交互的方式。
5. **馆员人力有限**：难以实现"千人千面"的精细化服务，重复咨询消耗大量人力。

### 2.2 问题本质

上述痛点的本质是：**传统图书馆是"以资源为中心"的被动服务，而非"以人为中心"的主动服务**。要实现转型，需要一个"懂读者、懂文化、懂服务"的智能中枢。

## 第三章 项目总体设计与创新定位

### 3.1 总体定位

做一座"会说话的图书馆"——以榆林本地文化为灵魂、以 AI Agent 为大脑、以分层技能库为手脚、以 MCP 数据服务为血脉的公共文化智慧服务系统。

### 3.2 三个"不做"与三个"要做"

| 维度 | 不做 | 要做 |
|---|---|---|
| 范围 | 大而全的智慧图书馆中台 | 小而精、专而暖的文化服务智能体 |
| 技术 | 通用大模型套壳问答 | 本地知识库 + 分层技能 + 数据服务闭环 |
| 内容 | 全国通用文化模板 | 专属榆林、专属路遥、专属陕北非遗 |

### 3.3 五大创新点

1. **本地文化知识库驱动的专属智能体**——知识库硬性限定六大领域，杜绝"答非所问"。
2. **分层 Skills 技能库**——能力组件化、可复用、可组合、可扩展，具备工程可维护性。
3. **MCP 数据服务架构**——AI 与图书馆数据的"标准桥梁"，统一、可替换、可审计。
4. **AI 智慧便民创新服务**——把图书馆升级为"文化陪伴者"。
5. **全人群覆盖的社会价值设计**——少儿、青少年、中老年各得其所。

## 第四章 技术架构设计

### 4.1 总体架构（三层四端）

系统采用"**三层四端**"架构：

- **四端**：读者小程序端、触屏一体机端、微信公众号端、馆员后台端。
- **第一层（AI 智能体层）**：「榆小图」Agent，负责意图识别、人群分层、任务规划、记忆管理。
- **第二层（Skills 技能库层）**：少儿、青少年、中老年三大技能组 + 跨人群通用技能。
- **第三层（MCP 数据服务层）**：馆藏、文化、用户、阅读、活动五大标准服务。

### 4.2 设计原则

1. **三层解耦**：Agent（大脑）、Skills（能力）、MCP（数据）各司其职，任一层替换/升级不影响其他层。
2. **数据标准化**：所有数据读写通过 MCP 标准接口，屏蔽底层异构。
3. **渐进落地**：模拟数据 → 部分真实数据 → 全量接入，平滑演进。

### 4.3 技术选型

前端采用单页 H5/小程序/触屏 Web，零安装；智能体采用大语言模型（可本地部署或 API 调用）；技能库采用 JSON 结构化定义；数据服务采用 MCP 标准接口；知识检索采用向量检索 + 关键词匹配。

---

## 第五章 AI 智能体「榆小图」设计

### 5.1 身份设定

「榆小图」是榆林图书馆专属文化服务智能体，形象为"头戴陕北头巾、手持书卷的图书馆小书童"，性格温和耐心、循循善诱，具备"蹲下来和孩子说话、放大字号和老人说话"的差异化沟通能力。

### 5.2 知识库规则

知识库硬性限定六大领域：榆林馆藏、路遥文化、陕北民俗、陕北非遗、红色文化、榆林地方文献。采用**白名单优先、来源可溯、事实准确、价值观安全**四大规则，确保"专属榆林、不杜撰"。

### 5.3 对话逻辑

四步对话引擎：**意图识别 → 人群分层 → 技能调度 → 生成与回写**。通过"意图 + 人群"的交叉匹配，实现"千人千面"的差异化服务。

### 5.4 六项硬性能力

智能图书推荐、榆林本地文化问答、少儿科普/老年简易咨询、阅读计划定制、活动文案生成、馆藏通俗化解读。

---

## 第六章 分层 Skills 技能库设计

### 6.1 设计理念

"能力组件化、分层可复用、按需自动触发"。每个 Skill 是标准化能力单元，包含 `id / name / target / trigger / action` 五字段。

### 6.2 技能库全景

- **少儿技能组（4 项）**：趣味文化科普、故事改编、绘本文案、简单诗词解读。
- **青少年技能组（4 项）**：阅读导读、名著拆解、路遥作品深度解析、作文素材生成。
- **中老年技能组（4 项）**：极简咨询、大字版解读、通俗文化讲解、老年活动推荐。
- **通用技能组（4 项）**：智能荐书、阅读计划定制、活动策划文案、无障碍智能适配。

共 **16 项技能**，覆盖三类人群 + 跨人群通用场景，全部结构化定义于 `skills_catalog.json`，可维护、可扩展、可版本管理。

---

## 第七章 MCP 数据服务架构设计

### 7.1 总体设计

采用 MCP 协议统一数据服务，设计 5 大标准服务：

1. **馆藏资源服务**（`mcp.yulin.catalog`）：检索、详情、借还状态、位置指引。
2. **文化知识库服务**（`mcp.yulin.culture`）：知识检索、分级解读、分类树。
3. **用户画像服务**（`mcp.yulin.profile`）：轻量脱敏画像、个性化推荐。
4. **阅读计划服务**（`mcp.yulin.reading`）：计划定制、进度、打卡。
5. **活动事件服务**（`mcp.yulin.event`）：活动检索、文案生成、报名。

### 7.2 数据流转

读链路：意图 → 检索 → 召回 → 分级渲染；写链路：行为 → 脱敏 → 回写。采用三级缓存（会话缓存、高频缓存、持久存储）。

### 7.3 数据安全

用户画像仅保存轻量化脱敏字段（年龄区间、偏好类别、最近主题），不存姓名、手机号、精确位置；对话记忆会话级临时；数据仅用于个性化服务，符合《个人信息保护法》。

## 第八章 四大核心便民创新模块

1. **AI 图书馆陪伴阅读伙伴**：读前导读、读中陪读、读后讨论、打卡激励，把"借书"升级为"陪读"。
2. **榆林本地文化 AI 科普专栏**：每日一非遗、路遥金句台历、民俗问答、红色记忆，让非遗"开口说话"。
3. **活动策划文案自动生成**：读书会、展览、研学三类活动的主题、招募文案、环节、讨论题一键生成。
4. **特殊人群无障碍智能服务**：大字版、语音播报、简化交互、方言支持、适老配色，跨越数字鸿沟。

## 第九章 三类人群差异化服务

- **少儿**：趣味科普、故事改编、绘本、简单诗词、互动激励，重在"播下种子"。
- **青少年**：导读、名著拆解、路遥深度解析、作文素材、阅读计划，重在"汲取力量"。
- **中老年**：极简咨询、大字解读、通俗讲解、适老活动、方言语音，重在"跨越鸿沟"。

底层由人群判定引擎、技能分层路由、无障碍适配层、脱敏画像共同支撑。

## 第十章 落地价值与社会意义

### 10.1 落地价值

对读者：从"找书"到"被书找到"；对图书馆：从"人力瓶颈"到"智能倍增"；对文化：从"静态陈列"到"活态传播"；对成本：轻量化、渐进式、可落地。

### 10.2 社会意义

促进公共文化服务均等化、守护传播地方文化、弥合数字鸿沟、以文化人、助力全民阅读。

### 10.3 推广前景

架构天然可复制——任一地区图书馆只需替换本地文化知识库即可复刻。推广路径：榆林试点 → 县区推广 → 陕北区域复制。可延展至文旅、教育、政务融合。

### 10.4 未来迭代

真实数据接入、多模态交互、知识库扩容、个性化增强、跨馆协同、无障碍深化、开放平台。

「榆小图」不仅是一套技术系统，更是一份**用 AI 守护陕北文化、温暖每一位读者**的社会答卷。它用最小的成本、最暖的方式，让一座西北城市的图书馆，从"藏书楼"变成"文化陪伴者"，让路遥的奋斗精神、陕北的非遗技艺、榆林的红色记忆，在数字时代被新一代读懂、记住、传承。
