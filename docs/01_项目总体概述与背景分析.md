# 01 · 项目总体概述与背景分析

## 一、项目总体概述

**项目名称**：榆林图书馆「AI 融合的智慧服务创新」系统
**核心产品**：榆林图书馆文化服务 AI 智能体——「榆小图」
**面向人群**：青少年读者、老年读者、普通市民
**核心目标**：以榆林本地文化知识库为底座，以 AI Agent + 分层 Skills 技能库 + MCP 数据服务为技术内核，打造一套轻量化、可落地、可演示的图书馆 AI 智慧服务系统。

**本项目要回答的一个核心问题**：

> 如何让一座西北地区的市级公共图书馆，在不依赖巨额投入与复杂改造的前提下，用 AI 把"沉睡的馆藏"转化为"可陪伴、可对话、可传播的文化服务"？

**答案**：不做"大而全的智慧图书馆中台"，而是做一个**小而精、专而暖**的文化服务智能体——它懂榆林、懂路遥、懂陕北非遗，也懂老人和孩子。

---

## 二、项目背景

### 2.1 政策背景：公共文化服务数字化是国家意志

《"十四五"公共文化服务体系建设规划》明确提出"推动公共文化服务数字化、网络化、智能化"；《关于推进实施国家文化数字化战略的意见》要求公共文化机构加快数字化转型升级。人工智能作为新质生产力的代表，正在全面渗透公共文化服务领域。本项目正是"AI + 公共文化服务"在市级图书馆场景的一次具体落地。

### 2.2 地方文化背景：榆林是一座"被低估的文化富矿"

榆林市位于陕西省最北部，地处陕北黄土高原与毛乌素沙地交界处，是**国家级历史文化名城**，文化资源极为丰厚：

- **路遥文学**：当代著名作家路遥（1949—1992）生于榆林清涧县，代表作《平凡的世界》《人生》，深刻影响了中国几代青年。路遥既是榆林的文化名片，也是"奋斗精神"的象征。
- **陕北非遗**：陕北说书、榆林小曲、绥德剪纸、绥德石雕、陕北秧歌、横山老腰鼓、子洲唢呐、陕北道情等，均为国家级或省级非物质文化遗产。
- **红色文化**：榆林是革命老区，清涧起义、小河会议（靖边小河村）等重大事件发生于此，毛泽东曾率中共中央转战陕北。
- **名胜古迹**：镇北台（"万里长城第一台"）、红石峡、白云山、统万城遗址（十六国大夏国都）、榆林古城（"南塔北台中古城，六楼骑街天下名"）。
- **地方文献**：榆林地方志、家谱、民俗志、红色档案等地方文献资源丰富。

**关键判断**：榆林不缺文化，缺的是"让文化被看见、被读懂、被年轻人喜欢"的数字化入口。

### 2.3 技术背景：AI Agent、Skills 与 MCP 已经成熟到可落地

- **大语言模型（LLM）**：具备成熟的对话、生成、理解能力，且推理成本持续下降，本地化部署与轻量调用均已可行。
- **AI Agent**：从"单一对话机器人"进化为"能调度工具、能调用知识、能规划任务的智能体"。
- **Skills 技能库**：把 AI 能力"组件化、标准化、可复用化"，让不同场景按需调用。
- **MCP（Model Context Protocol）**：由 Anthropic 提出的开放协议，让大模型以统一标准连接外部数据源与工具，是"AI 连接图书馆数据"的关键桥梁。

三者结合，恰好构成"**智能体（大脑）+ 技能库（能力）+ MCP（数据血脉）**"的可落地技术范式。

## 三、痛点分析

### 3.1 资源利用率低：馆藏"沉睡"严重

传统图书馆的馆藏资源以"被动等待"为主，读者不知道"有什么、适不适合我、怎么读"。大量地方文献、古籍、非遗资料因"专业性强、门槛高"而长期无人问津。

### 3.2 服务形式枯燥：缺乏"对话感"与"陪伴感"

读者到馆的体验仍是"查目录—找书—借书—还书"的线性流程，缺少个性化推荐、趣味互动与持续陪伴，难以吸引数字原生代的青少年读者。

### 3.3 特殊人群使用门槛高：老年人被"数字鸿沟"挡在门外

老年读者面对智能检索、自助借还、App 操作等数字服务往往无所适从；同时，字号过小、术语过多、界面复杂，进一步拉高了使用门槛。

### 3.4 文化传播单一：陕北文化"叫好不叫座"

榆林本地文化（路遥、非遗、红色、地方文献）传播仍以静态展览、纸质宣传为主，缺乏年轻化、趣味化、可交互的传播方式，文化传播"有存量、缺增量"。

### 3.5 馆员人力有限：难以做到"千人千面"的精细化服务

基层图书馆馆员人手有限，难以对每一位读者提供个性化的阅读指导、活动策划与深度咨询，服务质量受限于人力。

**痛点总结为一句话**：

> 资源在沉睡、服务在等待、老人在门外、文化在墙上、馆员不够用。

## 四、解决方案总览（对应痛点）

| 痛点 | 本项目对应方案 | 核心手段 |
|---|---|---|
| 馆藏沉睡、利用率低 | 智能图书推荐 + 馆藏通俗化解读 | Agent + 馆藏 MCP |
| 服务枯燥、缺乏陪伴 | 陪伴阅读伙伴 + 阅读计划定制 | Agent + 阅读计划 MCP |
| 老人门槛高、数字鸿沟 | 极简咨询 + 大字版解读 + 无障碍适配 | 分层 Skills |
| 文化传播单一 | 本地文化科普专栏 + 活动文案自动生成 | 文化知识库 + Skills |
| 馆员人力有限 | AI 分担重复咨询与文案工作 | Agent 全时在线 |

---

## 五、项目目标体系

1. **效率目标**：把"查书、问书、荐书"的常见咨询自动化，降低馆员重复劳动。
2. **体验目标**：让每一位读者（尤其是老人、孩子）都能"说句话就得到服务"。
3. **文化目标**：让路遥文学、陕北非遗、红色文化以"可对话、可阅读、可传播"的方式触达新一代。
4. **落地目标**：轻量化、低成本、无真实后端即可演示，可平滑接入真实馆藏系统。
