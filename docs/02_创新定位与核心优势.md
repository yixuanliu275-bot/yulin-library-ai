# 02 · 项目创新定位与核心优势

## 一、创新定位

### 1.1 一句话定位

**做一座"会说话的图书馆"——以榆林本地文化为灵魂、以 AI Agent 为大脑、以分层技能库为手脚、以 MCP 数据服务为血脉的公共文化智慧服务系统。**

### 1.2 三个"不做"与三个"要做"

| 维度 | 不做（行业常见误区） | 要做（本项目的选择） |
|---|---|---|
| 范围 | 不做"大而全的智慧图书馆中台" | 做"小而精、专而暖"的文化服务智能体 |
| 技术 | 不做"通用大模型套壳问答" | 做"本地化知识库 + 分层技能 + 数据服务"三层闭环 |
| 内容 | 不做"全国通用文化模板" | 做"专属榆林、专属路遥、专属陕北非遗"的定制内容 |

### 1.3 差异化关键词

**"本地化 × 陪伴化 × 全人群 × 轻落地"** —— 这四点的交集，正是本项目区别于普通图书馆数字化项目的根本所在。

---

## 二、核心创新点（五大创新）

### 创新点一：本地文化知识库驱动的"专属智能体"

区别于市面上"通用大模型问答"，「榆小图」的知识库被**硬性限定**在六个领域：榆林馆藏、路遥文化、陕北民俗、陕北非遗、红色文化、榆林地方文献。所有回答都从本地知识库检索生成，杜绝"张冠李戴、答非所问"，真正实现"**专属榆林图书馆**"。

### 创新点二：分层 Skills 技能库——让 AI 能力"可复用、可组合、可扩展"

把 AI 能力拆解为标准化技能单元（Skill），并按**人群分层**（少儿 / 青少年 / 中老年）组织：

- 技能即"能力组件"，可被 Agent 按场景**自动触发**；
- 技能即"知识资产"，可被馆员**按需维护**；
- 技能即"扩展接口"，新场景只需新增一个 Skill，无需重写系统。

这使系统具备真正的**工程化可维护性**，而非"一次性演示"。

### 创新点三：MCP 数据服务架构——AI 与图书馆数据的"标准桥梁"

采用 MCP（Model Context Protocol）统一数据服务规范，将馆藏、用户画像、文化知识、阅读计划、活动事件抽象为**五个标准 MCP 服务**。这使得：

- AI 无需理解各系统的异构接口，**统一通过 MCP 读写数据**；
- 未来接入真实 ILS（图书馆集成系统）、地方文献库时，**只需替换 MCP 服务实现**，上层 Agent 与 Skills 零改动；
- 数据流转**结构化、可审计、可脱敏**，满足公共文化机构的数据安全要求。

### 创新点四：AI 智慧便民创新服务——把"图书馆"升级为"文化陪伴者"

在传统"借还书"之外，首创四类便民服务：

1. **AI 陪伴阅读伙伴**——从"借一本书"到"陪读一本书"；
2. **榆林本地文化 AI 科普专栏**——让非遗"开口说话"；
3. **读书会/展览/研学活动文案自动生成**——馆员策划的"AI 助手"；
4. **特殊人群无障碍智能服务**——老人孩子都能用。

### 创新点五：全人群覆盖的社会价值设计

系统并非只服务"会用手机的人"，而是通过**差异化分层**，让**少儿、青少年、中老年**三类人群各得其所——这既是产品设计，更是**公共文化服务的公平性主张**。

## 三、核心优势（相对竞品/普通方案）

### 3.1 技术优势：三层解耦，架构先进

Agent（调度）— Skills（能力）— MCP（数据）三层解耦，职责清晰、边界明确，具备工程化的可维护性与可扩展性，符合软件工程最佳实践。

### 3.2 文化优势：本地化知识库，不可复制

路遥文学、陕北非遗、红色文化、榆林地方文献构成了**独一无二的知识资产**。这套知识库一旦建成，即成为榆林图书馆的**数字文化护城河**，其他地区无法简单复制。

### 3.3 成本优势：轻量化，可落地

无需真实后端数据库、无需大规模硬件改造，以**模拟数据架构**即可完成完整演示；真实落地时按 MCP 标准渐进接入，**初期成本极低、见效极快**。

### 3.4 人群优势：全年龄覆盖，社会价值高

从少儿趣味科普到老年极简大字服务，覆盖人生全阶段，直接呼应"公共文化服务均等化"的政策要求，社会价值与政策契合度双高。

### 3.5 传播优势：年轻化、趣味化、可交互

以对话、科普、故事、绘本等年轻人喜闻乐见的形式传播陕北文化，破解"非遗叫好不叫座"的传播难题。

---

## 四、创新定位的一句话总结

> **让陕北文化被每个年龄读懂，让每本书找到它的读者，让图书馆从"藏书楼"变成"文化陪伴者"——这就是「榆小图」的使命。**
