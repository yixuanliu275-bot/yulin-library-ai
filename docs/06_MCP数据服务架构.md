# 06 · MCP 数据接口与数据流转方案

## 一、MCP 服务总体设计

采用 **MCP（Model Context Protocol）** 作为 AI 智能体与图书馆数据之间的统一数据服务标准。设计 **5 个 MCP 服务**，覆盖馆藏、文化、用户、阅读、活动五大数据域。

```
「榆小图」Agent 与 Skills
        │ 统一通过 MCP 协议调用（tool / resource）
        ▼
┌─────────────────────────────────────────────────────────┐
│  MCP 服务网关（统一鉴权 / 路由 / 脱敏 / 日志）              │
└───┬──────────┬──────────┬──────────┬──────────┬─────────┘
    ▼          ▼          ▼          ▼          ▼
 ┌──────┐  ┌──────┐  ┌──────┐  ┌──────┐  ┌──────┐
 │馆藏   │  │文化   │  │用户   │  │阅读   │  │活动   │
 │Catalog│  │Culture│  │Profile│  │Reading│  │Event  │
 └──────┘  └──────┘  └──────┘  └──────┘  └──────┘
```

## 二、五大 MCP 服务接口定义

### 2.1 MCP-01 馆藏资源服务（`mcp.yulin.catalog`）

| 工具方法 | 输入 | 输出 | 说明 |
|---|---|---|---|
| `search_books` | 关键词、分类、年龄段、大字号 | 馆藏列表（书目、索书号、位置、适龄） | 智能检索馆藏 |
| `get_book_detail` | 书目 ID | 书目详情、摘要、馆藏状态 | 单书详情 |
| `check_availability` | 书目 ID | 在馆/借出/预约状态 | 借还状态查询 |
| `list_locations` | 分类 | 馆藏楼层/书架定位 | 位置指引 |

**馆藏数据结构（结构化整理）**：

```json
{
  "book_id": "YL-000123",
  "title": "平凡的世界（全三册）",
  "author": "路遥",
  "category": "文学 / 当代小说",
  "tags": ["路遥", "奋斗", "陕北", "现实题材"],
  "call_number": "I247.5/L880",
  "location": "二楼文学区 A-03 架",
  "suitable_age": "14+",
  "has_large_print": true,
  "status": "在馆"
}
```

### 2.2 MCP-02 文化知识库服务（`mcp.yulin.culture`）

| 工具方法 | 输入 | 输出 | 说明 |
|---|---|---|---|
| `search_knowledge` | 关键词（路遥/非遗/民俗/红色/文献） | 文化条目（含正文、来源） | 本地文化知识检索 |
| `get_knowledge_detail` | 条目 ID | 详细释义（可分级：趣味/通俗/深度） | 分级解读 |
| `list_categories` | — | 文化分类树 | 六大领域分类 |

**文化知识条目结构**：

```json
{
  "knowledge_id": "CULT-路遥-001",
  "title": "路遥与《平凡的世界》",
  "domain": "路遥文化",
  "levels": {
    "kids": "一个叫孙少平的陕北哥哥努力读书改变命运的故事……",
    "teen": "《平凡的世界》全景式展现了……",
    "elder": "路遥是咱清涧人，写的都是咱陕北人的日子……"
  },
  "source": "《路遥传》"
}
```

### 2.3 MCP-03 用户画像服务（`mcp.yulin.profile`）

> **隐私优先**：仅保存轻量化脱敏字段，不存姓名/手机号/精确位置。

| 工具方法 | 输入 | 输出 | 说明 |
|---|---|---|---|
| `get_profile` | 匿名用户 ID | 年龄区间、偏好类别、最近主题 | 读取画像 |
| `update_profile` | 行为事件（脱敏） | 状态 | 轻量回写 |
| `get_recommendations` | 画像 ID | 个性化推荐清单 | 基于画像推荐 |

**用户画像结构（轻量化）**：

```json
{
  "user_id": "ANON-2026-0001",
  "age_group": "elder",
  "preferences": ["路遥", "大字版", "陕北民歌"],
  "recent_topics": ["平凡的世界", "陕北说书"],
  "reading_level": "通俗"
}
```

### 2.4 MCP-04 阅读计划服务（`mcp.yulin.reading`）

| 工具方法 | 输入 | 输出 | 说明 |
|---|---|---|---|
| `create_plan` | 书目/主题、周期、人群 | 阅读计划（分日任务、打卡点） | 定制计划 |
| `get_plan` | 计划 ID | 计划进度 | 读取进度 |
| `check_in` | 计划 ID、日期 | 打卡状态 | 打卡记录 |

### 2.5 MCP-05 活动事件服务（`mcp.yulin.event`）

| 工具方法 | 输入 | 输出 | 说明 |
|---|---|---|---|
| `list_events` | 人群、类型 | 活动列表 | 活动检索 |
| `generate_plan_text` | 活动类型（读书会/展览/研学） | 策划文案 | 文案生成 |
| `register_event` | 活动 ID、匿名用户 ID | 报名状态 | 报名登记 |

## 三、数据流转逻辑

### 3.1 读链路（检索 → 召回 → 渲染）

```
Agent 意图 → MCP-Culture 检索文化条目 → MCP-Catalog 检索馆藏
          → 按人群分级取 level → 按人群模板渲染输出
```

### 3.2 写链路（行为 → 脱敏 → 回写）

```
用户交互行为 → 脱敏抽取（仅保留：年龄区间/偏好类别/阅读主题）
          → MCP-Profile 轻量回写 → 下次推荐个性化增强
```

### 3.3 三级缓存策略

| 级别 | 内容 | 作用 |
|---|---|---|
| L1 会话缓存 | 当前对话上文 | 多轮连贯 |
| L2 高频缓存 | 热门馆藏、常用文化条目 | 减少重复检索 |
| L3 持久存储 | 馆藏库、知识库、画像库 | 数据底座 |

## 四、模拟数据架构（无真实后端即可演示）

**设计原则**：以 **JSON 结构化数据**模拟真实数据库，接口行为与真实 MCP 服务一致，落地时"**换数据源，不换协议**"。

| 模拟数据文件 | 对应 MCP 服务 | 内容 |
|---|---|---|
| `data/catalog_sample.json` | MCP-Catalog | 馆藏书目样例（路遥作品、非遗图书、地方文献） |
| `data/skills_catalog.json` | Skills 引擎 | 技能库结构化定义 |
| `data/user_profile_sample.json` | MCP-Profile | 脱敏画像样例 |
| `data/mcp_servers.json` | 网关 | 5 大服务接口元定义 |

> 详见 `data/` 目录下的结构化文件，可直接被前端 Demo 读取调用。

## 五、数据安全与合规

1. **最小化采集**：仅采集服务必需的轻量字段。
2. **全程脱敏**：不存储任何可直接识别个人身份的信息。
3. **用途限定**：数据仅用于个性化文化服务，不用于商业用途。
4. **可删除**：用户可随时清除画像，符合《个人信息保护法》要求。
